# Aviso de privacidad propuesto para SnackUp

SnackUp trata el nombre, correo institucional, número de control, identificador
de cuenta, pedidos, preferencias y reseñas necesarios para autenticar a la
persona, preparar y entregar pedidos, conservar su historial y mejorar el
servicio de cafetería.

No se deben almacenar contraseñas fuera de Firebase Authentication ni datos
completos de tarjetas. Los datos se compartirán únicamente con personal
autorizado y proveedores tecnológicos indispensables para operar el servicio,
con medidas de seguridad acordes al riesgo.

La persona puede solicitar acceso, rectificación, cancelación u oposición, así
como información sobre la conservación o eliminación de sus datos, mediante
`soporte.snackup@gmail.com`. El responsable institucional, domicilio, plazos y
procedimiento deben completarse y aprobarse antes de publicar este aviso.

Los cambios materiales se comunicarán dentro de SnackUp y se identificará la
fecha y versión del aviso. Esta propuesta no debe publicarse como aviso oficial
hasta recibir aprobación institucional.
